# 代理自定义充值比例

## 功能范围

该功能允许平台管理员为单个代理开通自定义充值定价。获得权限后，代理可为所属站点设置一个统一比例，美元余额和图片积分充值都使用该比例。

- 管理端入口：`/admin/agents`
- 代理端入口：`/agent/system`
- 用户端入口：`/user/recharge`
- 支付明细：`/admin/payment-orders`、`/admin/agent-cash`、`/agent/payments`

代理自定义比例只影响其所属用户的到账资产，不改变代理与平台的固定结算比例。

## 计费规则

允许设置范围：

```text
0.01 <= 自定义比例 <= min(余额结算比例, 图片积分结算比例)
```

以用户支付 `100 CNY`、代理自定义比例 `1`、平台结算比例 `7` 为例：

```text
用户到账 = 100 * 1 = 100 USD 或 100 图片积分
代理成本 = 100 / 7 = 14.29 CNY
代理现金分润 = 100 - 14.29 = 85.71 CNY
```

下单时会保存用户比例、代理结算比例、到账资产和现金分润快照。之后修改配置不会重算已有订单。

## 套餐规则

代理启用自定义定价后，其所属用户只能在线充值美元余额和图片积分：

- 用户充值页隐藏套餐付费入口。
- 套餐列表接口返回空列表。
- 服务端拒绝创建新的套餐充值订单。

配置切换前已经创建的待支付套餐订单继续按订单快照处理。已有套餐、代理库存及人工发放套餐不受影响。

关闭自定义定价权限后，用户恢复平台普通充值比例；套餐入口是否恢复取决于代理原先保存的套餐在线充值开关。

## 权限与审计

- 管理员负责授予或收回 `custom_recharge_rate_enabled`。
- 代理只能在获权后修改 `custom_recharge_rate`，不能修改自身权限。
- 创建时授权、后续权限变更和代理比例变更都会写入 `operation_log`。
- 配置和对应日志在同一数据库事务提交；日志失败时配置同步回滚。

支付决策以登录用户的 `user.agent_id` 为准。请求域名只参与品牌展示、归属校验、来源快照和支付回跳，不能绕过代理策略。

## 数据库升级

发布前先备份数据库，再执行：

```text
backend/sql/upgrade_agent_custom_recharge_rate_20260812.sql
```

脚本幂等新增：

- `agent.custom_recharge_rate_enabled`
- `agent.custom_recharge_rate`
- `payment_recharge_order.user_recharge_rate`

脚本中的 `@max_custom_recharge_rate` 默认按当前结算上限 `7` 检查已授权代理。若存在超限比例，脚本会以 SQLSTATE `45000` 终止升级。若生产配置的固定结算上限不同，应先调整该会话变量；遇到阻断时需先修正比例或关闭对应代理权限，再重新执行脚本。

发布顺序：数据库备份、执行升级 SQL、校验字段、发布后端、构建前端、健康检查。

## 回滚

业务回滚优先在管理端关闭代理的自定义定价权限。新订单会恢复平台普通用户比例，套餐入口恢复到原始套餐开关状态。

代码回滚时保留新增字段和历史订单快照。不要重算历史订单、代理现金余额或现金流水。
