API Key 每日最大额度

功能日期：2026-10-14。用户在 /user/api-keys 为每个 Key 单独设置每日最大美元额度。留空为不限额；支持正数、最多六位小数，最高 1,000,000,000 美元。

计数和限制

每个 Key 综合累计余额、套餐（含美元额度和 Token 额度）及赠送额度对应的请求美元消费价值，口径与该 Key 的累计美元消耗和消费账单一致。金额在资金来源拆分前计算，因此不会因使用套餐或赠送额度而少计。缓存读取和缓存创建按各自实际价格计入，全量缓存输入不会重复收取普通输入费用。

每日周期为北京时间 00:00–24:00，按结算完成日期归属，跨日自动重新累计，无需定时任务。页面显示服务端计算的日期和今日用量，点击“刷新用量”获取最新数据。

例如上限为 300 美元，今日累计达到或超过 300 美元后，该 Key 的后续新生成请求停止。HTTP 返回 429：

{
  "code": "API_KEY_DAILY_LIMIT_EXCEEDED",
  "message": "当日请求已超出设置最大额度",
  "data": null
}

普通和原生 Responses WebSocket 在每轮生成时读取最新额度，返回 type=error、status=429，内层 error 包含 type=rate_limit_error、相同 code 和中文 message，然后关闭会话。

已发出的请求正常完成并结算，单次或并发在途请求可能使最终用量超出上限；本功能不预留金额或取消在途请求。既有视频任务查询、下载和补结算、模型列表及 count_tokens 保持可用。独立图片/视频积分没有美元汇率，不折算到美元计数；Key 达到美元上限后也停止新的积分生成请求。

设置与重置

操作效果
创建 Key 时设置 / 点击设置限额更新上限；今日用量保留。降低到已使用额度以下会立即限制新请求。
重置今日用量确认后清零该 Key 的今日用量，保留每日上限、累计统计和历史账单；可以继续使用。在途请求完成后仍计入当日。
原有重置用量统计只清零累计请求数、Tokens 和美元消耗，今日用量及限额保留。

各管理操作只允许 Key 所属用户执行。新视频任务固定归属创建任务的 Key，换 Key 查询和进程重启不会改变归属；创建 Key 已删除时仍完成用户账务，不将消费转计至查询 Key。历史任务快照未记录创建 Key 时保持原来的查询 Key 兼容口径。

管理接口

接口请求
POST /api/user/api-keys原创建字段，可附加 daily_limit_usd
PUT /api/user/api-keys/{id}/daily-limit{"daily_limit_usd": 300}，字段必填，null 表示不限额
PUT /api/user/api-keys/{id}/daily-usage/reset无请求体

Key 列表及修改/重置结果返回 daily_limit_usd、daily_used_usd、daily_usage_date 和 daily_limit_exceeded。不限额的 Key 也记录每日用量，之后设置上限时沿用今日计数。
