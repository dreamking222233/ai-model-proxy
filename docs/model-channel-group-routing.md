# 模型渠道分组与 API Key 路由

## 功能说明

模型分组按 `model_series` 管理。每个系列可以配置多个渠道分组，并指定一个启用的默认分组。模型渠道映射属于“具体模型 + 分组 + 渠道”，同一模型可以在不同分组使用不同上游渠道。

## API Key 模式

- 通用 Key：每个模型系列自动使用当前启用的默认分组，历史 Key 的空分组字段按此模式兼容。
- 专用 Key：绑定一个模型系列和一个分组，只能访问该系列、该分组存在有效映射的模型。
- Key 分组切换立即影响后续请求；分组停用后保留绑定关系并返回分组不可用提示。

## 路由与模型列表

所有代理协议、图片和视频入口先解析 Key 分组，再在该分组内执行渠道启用、健康、熔断和优先级筛选。组内渠道全部不可用时不跨组回退。`/v1/models` 和 `/models` 返回当前 Key 实际可用的模型。

## Token 计费

文本 Token 计费最终倍率为：

```text
分组倍率 ×（用户独立倍率或模型系列全局倍率）× Fast 倍率 × 长上下文倍率
```

图片、视频、按请求和套餐官方额度沿用原有计费逻辑，不乘分组倍率。请求日志、消费记录和异步视频任务保存分组 ID、名称及倍率快照，用于历史审计。

## 管理入口

- `/admin/model-groups`：创建、编辑、停用、删除和设置系列默认分组。
- `/admin/models`：为模型渠道映射选择同系列分组。
- `/user/api-keys`：创建或修改通用/专用 API Key。
- `/admin/logs`、`/admin/agent-logs`：查看请求实际使用的分组和快照倍率。
