# API 密钥每日限额实施记录

## 任务概述

按经过两轮评估并通过的方案 v2 实现每 Key 每日 USD 上限、北京时间每日零点计数滚动及独立当日重置。共同结算累计所有资金来源拆分前的美元消费价值；上限为 NULL 时也累计。达到上限后新生成请求返回 HTTP 429、API_KEY_DAILY_LIMIT_EXCEEDED、当日请求已超出设置最大额度。HTTP 既有任务取回、模型列表、count_tokens 豁免。

## 核心口径与边界

同事务使用现有 ConsumptionRecord.total_cost / Key.total_cost 的请求消费美元值；不累计余额实际扣减或套餐 Token 数。日期在取得行锁后按结算日取值，过日只读显示为零，下次结算滚动日期。设置上限保留今日用量；今日重置保留上限和累计；原累计重置不会绕过每日限额。

正在执行的请求正常结算，单次/并发在途请求可能超出上限，后续准入拒绝。图片/视频积分没有美元换算规则，因此不会将积分数相加到美元；达到美元上限仍阻断积分生成。
