# 代理自定义充值比例实施记录

## 任务概述

本次新增代理站自定义用户充值比例能力：

- 管理员在 `/admin/agents` 授予或收回代理自定义定价权限。
- 获得权限的代理在 `/agent/system` 设置统一充值比例。
- 美元余额与图片积分共用该比例，代理结算比例仍读取平台固定配置。
- 用户支付金额减去按固定结算比例计算的代理成本，差额进入代理人民币现金分润。
- 自定义定价生效时，代理站用户看不到套餐付费入口，套餐列表为空，服务端拒绝创建新的套餐订单。
- 已创建的待支付订单继续按下单快照处理，不重写或取消历史订单。

## 核心代码说明

### 权威策略

`AgentService.resolve_user_recharge_policy(db, user)` 是登录用户在线充值规则的权威入口：

```text
平台用户：余额和图片积分分别使用平台用户比例
代理用户未授权：余额和图片积分分别使用平台用户比例
代理用户已授权：余额和图片积分统一使用 agent.custom_recharge_rate
```

当账号关联的代理不存在、已停用，或启用中的比例非法/超限时，接口失败关闭，不回退为平台用户规则。请求域名继续负责站点展示、账号归属校验、来源快照和支付回跳。

### 比例与分润

允许范围：

```text
0.01 <= custom_recharge_rate
     <= min(余额代理结算比例, 图片积分代理结算比例)
```

示例：统一比例 `1`、代理结算比例 `7`、用户支付 `100` 元：

```text
用户到账 = 100 * 1 = 100
代理成本 = 100 / 7 = 14.29 元
代理分润 = 100 - 14.29 = 85.71 元
```

余额和图片积分使用同一公式。订单创建后保存 `user_recharge_rate`、`agent_settlement_rate`、到账资产和代理分润，支付回调不重新读取当前配置。

### 套餐规则

有效套餐在线购买条件：

```text
在线充值总开关
AND 套餐原始开关
AND 未启用自定义定价权限
```

登录用户配置、套餐列表和创建订单统一消费同一用户归属策略。配置切换前已创建的待支付套餐订单仍可按原订单完成，切换只限制新订单。

### 推广奖励与审计

推广奖励继续按订单实际到账资产计算，由平台承担，不修改代理订单现金分润。管理员创建时授权、后续权限变更、代理比例与套餐原始开关变更均写入 `operation_log`，包含来源、操作人、代理 ID 和前后值。配置变更和日志使用同一数据库事务，审计写入或最终提交失败时统一回滚。
