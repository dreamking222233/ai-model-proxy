## 核心实现

沿用原来的大小写无关请求头索引，输出规范名称 `X-Claude-Code-Session-Id` 与 `X-Claude-Code-Agent-Id`。空值或非字符串值在现有索引构建时过滤；有效标识去除两端空白。

不生成新的会话标识，不将多个 agent 统一到 main；缺失标识时 CPA 的原 metadata fallback 继续可用。客户端认证、Cookie、任意扩展头仍不透传，渠道认证逻辑保持原样。其他协议分支不新增这些 Claude Code 专用头。

没有修改 system、tools、messages、计费逻辑或数据库结构；动态 MCP 说明和最终出站 Session-Id/session_id 兼容另需取证。
