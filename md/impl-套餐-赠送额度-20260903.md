# 套餐赠送额度实施记录

日期：2026-09-03

## 已完成

- 新增赠送批次与 rolling 24h 周期 ORM 及服务。
- 管理端新增赠送额度创建、列表、取消接口。
- 套餐模板支持 `all_models/selected_series`、系列多选和实例系列快照字段。
- 模型管理支持 `bonus_quota_enabled` 与 `billing_config_version`。
- 渠道增加 `video_billing_evidence_mode` 配置和校验。
- 代理扣费链路在模型开启赠送额度时先消费赠送周期，再执行套餐/余额逻辑，并记录赠送消耗量。
- 管理端套餐页面新增系列选择和赠送弹框；模型页面新增赠送开关。
- 用户 `/user/balance` 与管理端 `/admin/subscription` 当前套餐列表展示赠送批次的每日额度、已用、剩余、到期时间及适用模型系列。
- 赠送弹框支持按模型系列多选；套餐模板编辑会保留模型范围与系列配置；创建赠送后自动刷新当前套餐用户列表。
- 修复额度策略构建函数缺少返回值导致套餐额度摘要/扣费策略为空的问题，并修正用户端额度与模型格式化函数的 Vue 计算属性误用。
- 新增升级 SQL 与模型系列共享常量。
