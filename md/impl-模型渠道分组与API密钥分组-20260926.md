# 模型渠道分组与 API Key 分组实施记录

## 任务概述

按 Plan v2 为模型系列增加渠道分组、默认组、专用/通用 API Key、分组路由、Token 分组倍率及管理端页面，并保留历史 API Key 的默认组兼容行为。

- 测试：`backend/test_model_group_routing.py`（新增分组路由、模型列表和倍率叠加覆盖）

## 核心实现

1. `ModelGroup` 以 `model_series + code` 唯一，映射唯一键调整为 `unified_model_id + group_id + channel_id`。
2. 历史 Key 的空分组字段按 `unified` 处理；专用 Key 校验单一系列和启用分组。
3. 共享路由上下文为通用 Key 解析系列默认组，为专用 Key 校验系列并固定绑定组；候选渠道只在组内按原有健康、熔断和 priority 选择。
4. `/v1/models`、`/models` 过滤为 API Key 实际可用模型；Chat、Responses、Anthropic、原生透传、图片和视频均使用分组候选。
5. Token 文本计费使用 `分组倍率 × 用户独立/系列全局倍率 × Fast × 长上下文`，计费上下文冻结分组快照；图片、视频、按请求和套餐官方额度不乘分组倍率。
6. 日志、消费记录及视频任务快照记录分组 ID、名称和倍率快照。
