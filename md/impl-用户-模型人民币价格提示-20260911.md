# 用户-模型人民币价格提示 Impl

## 任务概述

在用户 `/user/models` 页面为符合条件的 Token 模型价格增加人民币参考价。参考价只在当前用户实际可用在线充值且余额充值比例为 1 人民币 = 5 美元时显示。

## 文件变更清单

- `backend/app/api/user/models.py`
  - 新增 `_cny_pricing_context()`，复用 `AgentService.resolve_user_recharge_policy()` 判断当前用户充值条件。
  - `/api/user/models` 的每个模型返回 `cny_price_enabled` 和 `cny_price_rate`。
- `frontend/src/views/user/ModelList.vue`
  - Token 模型 Input/Output 美元价格下方增加绿色小字人民币参考价。
  - 参考价按美元价格除以接口返回比例计算，并格式化最多 6 位小数。
- `backend/test_user_models_cny_pricing.py`
  - 覆盖标准 5 倍在线充值、关闭在线充值、非标准充值比例，并通过真实代理策略解析验证联动条件。
- `md/plan-用户-模型人民币价格提示-20260911.md`
  - 记录实施方案。

## 核心代码说明

`AgentService` 已统一处理平台支付开关、代理在线充值开关、代理自定义充值比例和代理状态。模型接口仅判断最终策略的 `online_recharge_enabled` 与 `balance_recharge_rate == 5`，因此不会误用订阅充值开关，也不会把其他代理比例显示成 1:5。

前端仅在 Token 价格结构中渲染提示，例如 `$5 /1M` 下显示 `= ¥1 /1M`；按请求、图片积分和免费模型不显示该提示。
