# 用户-模型人民币价格提示 Plan

## 用户原始需求

在 `/user/models` 页面美元模型价格后增加人民币参考价，帮助用户理解 1 人民币兑换 5 美元的充值逻辑。仅当当前站点开通用户前台在线充值且实际余额充值比例为 1 人民币 = 5 美元时显示；代理关闭前台在线充值或使用其他充值比例时不显示。

## 技术方案设计

- 复用后端 `AgentService.resolve_user_recharge_policy()` 解析当前登录用户的平台/代理充值策略。
- `/api/user/models` 在每个模型项返回 `cny_price_enabled` 和 `cny_price_rate` 字段；展示条件为在线充值有效且余额充值比例等于 5。
- Token 模型的 Input/Output 美元价格分别除以 `cny_price_rate`，在价格下方以绿色小字显示人民币 `/1M` 参考价。
- 非 Token 计费模型不新增人民币提示，避免把图片积分或按次美元价格误套用到 Token 价格说明上。
- 代理配置、支付配置和现有模型字段保持兼容，未满足条件时接口明确返回关闭标记。

## 实施步骤概要

1. 在用户模型接口解析充值策略并生成人民币提示元数据。
2. 在模型卡片 Token 价格下增加条件式人民币参考价。
3. 增加平台、标准代理、关闭充值及非 5 倍代理场景测试。
4. 运行后端测试、编译检查和前端 lint/build。
5. 创建实施记录并进行代码自审。
